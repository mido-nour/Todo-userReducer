# Todo-userReducer – Week 5

Simple Todo list app using useReducer and custom hook.

## What the app does
- Shows a list of tasks
- User can add a new task
- User can press a task to mark it done or undone
- User can remove a task by long press
- Tasks are stored in memory using useReducer

## Screenshots
Screenshots of the app UI are included in the images folder.

## Used tools
- React Native
- Expo
- TypeScript
- useReducer (state stored in memory)

## Files
- App.tsx – main app file (UI)
- hooks/useTodos.ts – reducer and task logic
- components/TaskRow.tsx – shows one task row
- types/task.ts – task type

## Run the app
npm install  
npx expo start
